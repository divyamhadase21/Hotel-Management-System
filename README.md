\# Hotel Management System



A web-based Hotel Management System developed using Java, JSP, Servlets, MySQL and Apache Tomcat.



\## Features



\- User Signup and Login

\- Room Management

\- Room Booking

\- Check-in and Check-out

\- Billing and Invoice

\- Meal Management

\- Banquet Booking

\- Forgot Password

\- Logout

\- Hotel Chatbot



\## Technologies Used



\- Java

\- JSP

\- Servlets

\- HTML

\- CSS

\- JavaScript

\- MySQL

\- Apache Tomcat

\- NetBeans



\## Database



MySQL is used as the database for storing hotel, room, booking and user information.



\## How to Run



1\. Install JDK.

2\. Install MySQL.

3\. Install Apache Tomcat.

4\. Open the project in NetBeans.

5\. Configure the MySQL database connection.

6\. Add the MySQL Connector/J library.

7\. Start Apache Tomcat.

8\. Run the project.



\## Project Structure



\- `src/java` - Java Servlets, DAO, Model and Database Connection

\- `web` - JSP pages, CSS and JavaScript

\- `nbproject` - NetBeans project configuration

\- `lib` - Required libraries
